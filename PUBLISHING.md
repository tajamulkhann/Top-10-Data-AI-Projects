# Repository maintenance

Repository: https://github.com/tajamulkhann/Top-10-Data-AI-Projects

Keep README.md at the root and preserve notebook execution outputs. After editing a project, run `python scripts/execute_all.py`, `python scripts/write_documentation.py` and `python scripts/verify_collection.py`. For Engineering changes, run `python scripts/execute_all.py data-engineering`, `python scripts/write_de_documentation.py` and `python scripts/verify_data_engineering.py`. Review changes before committing.

GitHub displays saved notebook outputs. Download HTML dashboards to open them locally; the GitHub file browser does not execute them.
